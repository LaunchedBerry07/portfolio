# Service illustrations

Seven WebP illustrations used across the homepage service cards and the Services page. The six original transparent illustrations remain unchanged; the Audiovisual & Multimedia icon is a new, white-background illustration supplied for the Services page.

- `translation-localization-globe-dialogue.webp` — Translation & Localization
- `editing-proofreading-quill-magnifier.webp` — Editing, comparative revision & proofreading
- `mtpe-robot-linguistic-check.webp` — MTPE & linguistic QA
- `terminology-book-quill-magnifier.webp` — Terminology & editorial control
- `transcreation-book-butterfly.webp` — Transcreation & content adaptation
- `data-annotation-magnifier-labels.webp` — Data annotation
- `audiovisual-multimedia-clapperboard.webp` — Audiovisual & Multimedia (Services page only)

The source illustrations were prepared with transparent backgrounds and exported as 800 × 800 px WebP images. Homepage display size is 144 px on narrow screens and 160 px from the `sm` breakpoint. The Services page uses larger, responsive placements within the four core service modules and the complementary Data Annotation section. The HTML keeps the established filenames so the existing relative paths remain stable for GitHub Pages.


The Audiovisual & Multimedia illustration is displayed as one consolidated image rather than three separate interface icons. Its original white background is retained to match the service card.

### Services v18 visual refinements
- Translation & Localization and Terminology Management now include two editorial distinction panels each, using the existing pink callout treatment.
- The Services CTA illustration uses a left-to-right alpha fade so it blends into the navy CTA background without a hard vertical seam.
