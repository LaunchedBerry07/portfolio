# Actifs visuels

Les images intégrées sont actuellement des SVG locaux de remplacement, générés avec la palette du portfolio. Remplacez-les par vos photos et visuels définitifs dans les dossiers catégorisés (portrait, services, études de cas linguistiques, projets techniques). Les noms et chemins présents dans `src` des pages montrent précisément les emplacements utilisés. Les références locales évitent les dépendances à un service d’images externe.
