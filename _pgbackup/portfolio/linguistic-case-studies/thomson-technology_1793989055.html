Project overview

Translating the TSC 900 operations and maintenance manual

I translated 21,931 words from Canadian English into Canadian French for the Thomson Power Systems TSC 900 Transfer Switch Controller Operations and Maintenance Manual, reference PM151.

The manual documents an automatic transfer switch controller designed to manage the transfer between utility power and backup generator sources. It brings together information about hardware architecture, operator interfaces, communication connections, electrical monitoring, automated generator controls, configuration and maintenance procedures.

This was not simply a matter of translating equipment descriptions. The content explained how different parts of the controller interact and how the system manages power-source transitions. The terminology therefore had to reflect the distinctions between components, their respective functions and the operating sequences described in the manual.

The assignment had a documented deadline of 31 July 2018. This date refers to the project deadline, not to the publication date of the translated manual.

The Challenge

Preserving the logic of a technical system

One of the central challenges in translating an operations and maintenance manual is maintaining the relationships between the equipment's architecture and its operating instructions.

The TSC 900 uses two principal components: the Graphical HMI Controller (GHC) and the Switch Control Unit (SCU). Although they form part of the same controller, they have distinct functions.

The GHC provides the graphical human-machine interface for operators, while the SCU is responsible for transfer control and dedicated interfaces. The manual describes their functions and connections.

These distinctions matter linguistically: inconsistent component names or functional descriptions can make it harder to identify which unit performs an operation or where an instruction applies.

The manual also covers several interconnected technical areas:

  • Power-source transitions: transfer operations between available power sources.
  • Electrical monitoring: monitoring voltage and frequency across phases.
  • Telemetry: active telemetry data.
  • Generator control: automated backup-generator start and stop commands.
  • Communication and connectivity: GHC and SCU ports, including programming connections.
  • Configuration and maintenance: system setup, operation, inspection and maintenance.

The challenge was to preserve the technical distinctions and procedural logic across these related areas, rather than treating each description or instruction as an isolated passage.

Scope of Work

Translating the manual in its technical context

My assignment covered the Canadian French translation of the 21,931-word PM151 manual.

The documented scope included content relating to:

1. Hardware architecture and component identification

The manual distinguishes the GHC from the SCU and describes their roles. Component names and functional descriptions had to preserve this documented architecture.

2. Operator interfaces and communication connections

The documentation describes the operator-facing interface, communication ports and dedicated connections used for programming and interfacing. Translating this material involved preserving the distinctions between user interaction, communication functions and controller connections.

3. Electrical monitoring and transfer sequences

The manual addresses power-source transitions and the monitoring of voltage and frequency across multiple phases. The terminology had to make monitored parameters and transfer functions clear within the system.

4. Automated backup generator controls

The documentation also covers automated generator start and stop commands. These instructions had to remain distinct from descriptions of the transfer hardware.

5. Configuration, operation and maintenance

PM151 brings together system configuration, operation, monitoring and maintenance information. The translation had to preserve the distinctions between these content types.

Working with Technical Terminology

Following the system's architecture

A recurring consideration in this assignment was the relationship between terminology and function.

In specialized documentation, a term is not always meaningful on its own. Its meaning may depend on the component, operation or procedural stage it identifies.

The distinction between the GHC and SCU is a clear example. Both belong to the TSC 900 controller, but their functions are not interchangeable. Their names and descriptions must therefore remain distinct throughout the manual.

The same principle applies to power transitions, electrical monitoring and generator controls: connected concepts, but distinct system functions.

My focus was on maintaining the technical meaning of the source while producing clear, consistent Canadian French. This meant considering terminology in relation to the system's architecture and the operational context in which each instruction appeared.

Preserving Clarity Across Operational Procedures

Keeping instructions connected to their context

The purpose of an operations and maintenance manual is not merely to describe a product. It must also communicate how its components and functions are intended to be understood and operated.

For the TSC 900, this meant preserving distinctions between technical descriptions and instructions for configuration, monitoring, transfer and maintenance, while keeping terminology coherent throughout.

This is particularly important when several components participate in a larger operation. The GHC, SCU, power sources and generator controls must be presented as parts of one system without confusing their individual roles.

The assignment illustrates why technical translation requires attention to both terminology and the relationships expressed through the text.

Key Takeaway

In an operations manual, terminology must follow the system’s architecture and its operation.

This project demonstrates my experience translating specialized industrial documentation in which component relationships, electrical functions and operating sequences must remain clear in the target language.

By translating the 21,931-word PM151 manual from Canadian English into Canadian French, I worked with technical content spanning controller architecture, operator interfaces, communication connections, electrical monitoring and backup power management.

The central lesson is that technical accuracy depends on more than choosing the right equivalent for each term. It also requires preserving the functional distinctions and relationships that allow readers to understand the system as a whole.
