Project overview

Language shaped by gameplay context

Beholder is a narrative-driven PC game set in a tightly controlled, totalitarian society. Players take on the role of an apartment building manager whose work brings them into contact with tenants, official instructions, surveillance activities and consequential decisions.

Dialogue and interface text are part of the same experience: they help players understand characters, interpret information and decide what to do next. The assignment involved localizing the full game from English into French and reviewing the localized content in the game environment.

The Challenge

Making text work within a connected narrative

In Beholder, players move between conversations, tenant information, official instructions and decisions that can affect the story. Text therefore has to be understood in relation to the character, situation, interface and action it accompanies. A phrase that seems clear in isolation may read differently when placed in a profile, a report or a gameplay prompt.

Key considerations included:

  • Maintaining the meaning and tone of narrative dialogue within character interactions.
  • Keeping menus, profile fields and report-related text clear and usable.
  • Considering system messages and player-facing information in relation to the events they accompany.
  • Checking the wording of player choices within their surrounding gameplay context.
  • Identifying contextual issues, text truncation and interface constraints not apparent from isolated strings.

Scope of Work

Localization across the game experience

The assignment covered the game's player-facing text, including narrative dialogue, menus, system messages and choices. These elements serve different purposes: some establish atmosphere and character relationships, while others guide the player, present information or support an interaction.

The main content areas included:

  • Narrative dialogue and interactions: adapting character-facing text within the situations in which exchanges occur.
  • Menus and interface elements: reviewing concise labels and text within the screens where players encounter and use them.
  • System messages and player information: considering informational text in relation to the task, event or action it accompanies.
  • Choices and consequences: checking player-facing choices in the context in which decisions are made.

Review & playtesting

From translated strings to playable content

The localized content was reviewed in the game itself, allowing the text to be assessed as players would encounter it during gameplay.

Context is part of the text

Why in-context testing matters

A line can be linguistically sound on its own and still create a problem when it appears in a game. The available space, the character speaking, the information already shown on screen and the action being presented all influence how a text is understood.

Players experience a localized game through its dialogue, interfaces and decisions as one connected whole—not as a collection of independent strings.
