Introduction

This work complements my professional language practice. Translation and localization have taught me to pay attention to context, terminology, constraints and consistency across an entire system—not just isolated pieces of content. I apply the same mindset when designing workflows, defining rules or connecting tools.

The projects below are independent, internal or applied projects, rather than a list of commercial software products. Each case study describes the problem, the approach, the technologies involved and the project’s current scope, including limitations where relevant.

What these projects explore

AI instructions and structured reasoning

Designing reusable instructions, conditional routing and source-grounded templates that make complex tasks more consistent and reviewable.

Workflow automation and information management

Connecting documents, email, structured records and destination platforms while accounting for API constraints, traceability and human review.

Application design and practical tools

Building interfaces and data structures that help people organize information, inspect options or work with specialized systems.

Custom systems and interactive experiences

Combining domain knowledge, technical rules and writing to create a structured experience within an existing platform.

Drive-to-Notion Migration Pipeline →

Document processing · API integration

An automation pipeline that extracts text from supported Google Drive documents, creates structured Notion pages and preserves links to the original files. Batch processing, timed resumption and execution logs help manage runtime limits and troubleshooting.

What it demonstrates: Demonstrates document extraction, structured migration, source traceability and runtime-aware automation.

Project status: Used operationally. Image OCR was outside the documented workflow; reported processing scale has not been independently audited.

Google Workspace · Information management

A web application concept connecting email classification, document archiving and structured contact information. Implemented components include Gmail labels, an organized Drive folder structure, PDF generation and archiving, and a contact register. What it demonstrates: Demonstrates integration across Google Workspace services, interface design and human-in-the-loop workflow planning.

Accounting workflows · Low-code automation

Closing section

A practical, context-aware approach

Across these projects, I focus on making requirements explicit, structuring information before automating it, preserving links to source material, and identifying where human review is still needed. The right solution is not simply the one with the most automation; it is the one whose logic, limitations and outputs can be understood and checked.

My technical work remains closely connected to the way I approach language: context matters, consistency must be designed, and quality depends on the whole workflow as much as on its individual parts.
